## 1. 产品概述

统一账号认证服务（Unified Account Identification Service）是一个基于 Django + Django REST Framework 的多租户认证授权平台。

### 1.1 核心功能

| 功能模块 | 说明 |
|---------|------|
| **用户认证** | 用户名密码登录、手机验证码登录、社交账号登录（微信/钉钉/飞书） |
| **OAuth2.0 授权** | 标准授权码模式，支持第三方应用接入 |
| **应用管理** | AppKey + HMAC-SHA256 Signature API 认证 |
| **JWT Token** | 基于 JWT 的访问令牌，支持自动刷新 |
| **RBAC 权限** | 基于角色的访问控制，支持细粒度 API 权限管理 |
| **标签系统** | 用户标签管理，支持按标签筛选和分类 |
| **多租户** | 企业级多租户架构，租户间数据完全隔离 |
| **审计日志** | 完整的操作审计记录 |
| **请求限流** | 基于 IP 和 AppKey 的请求频率控制 |
| **管理后台** | 浏览器端管理面板，支持用户/应用/权限/角色管理 |

### 1.2 技术架构

- **后端框架**: Django 3.2 + Django REST Framework
- **数据库**: 开发环境 SQLite / 生产环境 MySQL
- **缓存**: Django Cache（支持 Redis）
- **认证方式**: JWT Bearer Token / AppKey + Signature / 超级管理员账号
- **中间件链**: TokenAuth → AppKeyAuth → AdminAuth → Permission → RateLimit → ApiStat → AuditLog → View

## 2. 快速开始

### 2.1 环境要求

- Python >= 3.8
- pip（Python 包管理器）
- MySQL 5.7+（生产环境）或 SQLite（开发环境）

### 2.2 安装步骤

```bash
# 1. 进入项目目录
cd code/unified_auth

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置环境变量
# 复制 .env.example 为 .env 并修改配置
cp .env.example .env

# 4. 执行数据库迁移
python manage.py makemigrations
python manage.py migrate

# 5. 初始化数据（创建默认租户和管理员）
python manage.py init_data

# 6. 启动开发服务
python manage.py runserver 0.0.0.0:8000
```

### 2.3 访问地址

| 服务 | 地址 |
|------|------|
| 管理后台 | http://localhost:8000/admin-panel/ |
| OAuth2 授权页 | http://localhost:8000/oauth/authorize |
| Django Admin | http://localhost:8000/admin/ |

```ini
# DB_USER=root

# DB_HOST=127.0.0.1
# DB_PORT=3306

# ==================== JWT ====================
```

### 3.4 Mock 模式


### 4.8 更新用户信息

**接口**: `PUT /api/v1/auth/me`

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `nickname` | string | 否 | 昵称 |

| `company` | string | 否 | 公司 |

### 4.9 修改密码

**接口**: `PATCH /api/v1/auth/me/password`

需要 Bearer Token 认证。通过原密码校验后修改密码。

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `old_password` | string | 是 | 旧密码 |
| `new_password` | string | 是 | 新密码（至少8位） |

### 4.9.1 短信验证码修改密码（无需原密码）

忘记原密码时，可通过当前用户绑定的手机号接收短信验证码来重置密码。手机号从用户 token 解析，不接受请求方指定。分两步完成：

```
① POST /api/v1/auth/sms/send/pwd   →  向当前用户绑定的手机号发送改密验证码（需 Bearer Token）
              │
              ▼   用户收到短信
② POST /api/v1/auth/me/password/reset   →  校验验证码 + 新密码，完成修改
```

**① 发送改密验证码**

**接口**: `POST /api/v1/auth/sms/send/pwd`

需要 Bearer Token 认证。无需请求体，手机号从用户 token 解析。

**成功响应** (200):

```json
{
    "code": 0,
    "message": "success",
    "data": {
        "phone": "13800138000"
    }
}
```

**② 验证码重置密码**

**接口**: `POST /api/v1/auth/me/password/reset`

需要 Bearer Token 认证。

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `code` | string | 是 | 短信验证码 |
| `new_password` | string | 是 | 新密码（至少8位） |

**成功响应** (200):

```json
{
    "code": 0,
    "message": "success",
    "data": {}
}
```

**失败响应** (400):

| 错误码 | 说明 |
|--------|------|
| `-10302` | 验证码已过期，请重新获取 |
| `-10301` | 验证码错误 |

> **说明**：改密验证码缓存于 `sms:pwd:{phone}`，与登录验证码（`sms:{phone}`）相互隔离，防止跨用途重放；验证码为一次性使用，校验通过后立即失效。若当前用户未绑定手机号，返回 400 错误。

### 4.10 获取/更新用户资料

**接口**: `GET /api/v1/auth/me/profile`  
**接口**: `PUT /api/v1/auth/me/profile`

需要 Bearer Token 认证。

用户资料字段包括：真实姓名（real_name）、性别（gender）、生日（birthday）、职位（job_title）、工号（employee_id）、工作邮箱（work_email）、工作电话（work_phone）等。

## 5. 开放 API（OpenAPI）（`/api/v1/open/`）

开放 API 提供外部应用调用的接口，采用 **AppKey + HMAC-SHA256 Signature 认证**。

### 5.1 认证方式

所有开放 API 请求需要在 Header 中携带以下参数：

| Header | 说明 |
|--------|------|
| `X-App-Key` | 应用标识，由管理后台生成 |
| `X-Timestamp` | 请求时间戳（毫秒） |
| `X-Signature` | HMAC-SHA256 签名 |

**签名算法**:

```python
import hashlib, hmac

def generate_signature(app_secret, method, path, timestamp, body=""):
    message = f"{method}\n{path}\n{timestamp}\n{body}"
    return hmac.new(
        app_secret.encode("utf-8"),
        message.encode("utf-8"),
        hashlib.sha256
    ).hexdigest()
```

### 5.2 验证 Token

**接口**: `POST /api/v1/open/verify_token`

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `token` | string | 是 | 需要验证的 access_token |

**响应示例**:

```json
{
    "code": 0,
    "data": {
        "valid": true,
        "user_id": 1,
        "tenant_id": 1,
        "user_type": "internal"
    }
}
```

### 5.3 用户管理

**接口**: `GET /api/v1/open/users` — 获取用户列表  
**接口**: `POST /api/v1/open/users` — 创建用户  
**接口**: `GET /api/v1/open/users/{id}` — 获取用户详情  
**接口**: `PUT /api/v1/open/users/{id}` — 更新用户  
**接口**: `PATCH /api/v1/open/users/{id}/status` — 更新用户状态

**GET 用户列表响应**:

## 6. OAuth2 授权（`/oauth/`）

系统支持标准的 OAuth2 授权码模式（Authorization Code Grant）。

### 6.1 授权流程

```
用户 → 第三方应用 → 本系统授权页 → 用户确认 → 授权码 → 换取 Token
```

### 6.2 获取授权码

**接口**: `GET /oauth/authorize`

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `app_key` | string | 是 | 应用标识 |
| `redirect_uri` | string | 是 | 回调地址 |
| `response_type` | string | 是 | 固定为 `code` |

用户访问此地址后会跳转到登录页面，登录成功后进入授权确认页。

### 6.3 确认授权

**接口**: `POST /oauth/authorize/confirm`

用户确认授权后，系统生成一次性授权码并回调到第三方应用的 `redirect_uri`。

### 6.4 换取 Token

**接口**: `POST /oauth/token`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `app_key` | string | 是 | 应用标识 |
| `app_secret` | string | 是 | 应用密钥 |
| `code` | string | 是 | 授权码 |
| `grant_type` | string | 是 | 固定为 `authorization_code` |

**响应示例**:

```json
{
    "code": 0,
    "data": {
        "access_token": "eyJ...",
        "token_type": "Bearer",
        "expires_in": 3600
    }
}
```

## 9. 管理后台使用指南

管理后台是一个浏览器端单页应用（SPA），地址为 `/admin-panel/`。

### 9.1 登录

1. 使用**超级管理员**账号（配置在 `SUPERADMIN_ACCOUNTS` 中）或**租户管理员**账号登录
2. 超级管理员可以管理所有租户，租户管理员只能管理自己租户下的资源
3. 登录后自动跳转到仪表盘页面

### 9.2 仪表盘

仪表盘展示租户级别的数据概览：

- **总用户数**：当前租户下的用户总数
- **在线用户**：近期活跃用户
- **应用数**：已接入的应用数量
- **活跃度**：用户登录活跃度
- **登录趋势图**：近7天登录趋势
- **登录分布**：不同登录方式的比例（密码登录/短信登录/社交登录）
- **用户增长图**：用户增长趋势
- **用户类型分布**：内部用户与外部游客的比例
- **活跃用户排行**：最活跃的用户排行
- **最近活动**：最近的操作记录

### 9.3 用户管理

#### 用户列表

- **搜索**：支持按用户名、手机号、邮箱搜索
- **筛选**：按状态（正常/禁用）和管理员身份筛选
- **分页**：每页 20 条记录

#### 单个用户操作

| 操作 | 说明 |
|------|------|
| 编辑 | 修改用户昵称、邮箱、手机号、部门、角色、管理员身份、用户类型 |
| 资料 | 查看/编辑用户的详细资料（真实姓名、性别、生日、职位等） |
| 标签 | 为用户设置标签（多选） |
| 类型 | 快速切换用户类型（内部用户 / 外部游客） |
| 启用/禁用 | 切换用户状态 |
| 重置密码 | 为用户生成新密码 |
| 删除 | 删除用户（仅已禁用的用户可以删除） |

#### 批量操作

1. 勾选需要操作的用户（全选勾选框在表头）
2. 点击对应的批量操作按钮：
   - **批量启用**：一键启用选中的用户
   - **批量禁用**：一键禁用选中的用户
   - **批量设置类型**：统一设置选中用户的类型
   - **批量删除**：删除选中的用户

#### 导入/导出用户

- **导出**：点击"导出用户"按钮，下载 CSV 格式的用户列表
- **导入**：点击"导入用户"按钮，上传符合格式要求的 CSV 文件

### 9.4 应用管理

在应用管理页面可以管理接入系统的第三方应用：

- **创建应用**：填写应用名称、回调地址、默认访问用户类型
- **编辑应用**：修改应用配置
- **应用密钥**：重置 AppSecret（重置后旧密钥立即失效）
- **配置微信**：为应用配置微信小程序/公众号/网站应用的 AppID 和 AppSecret
- **权限分配**：为应用分配 API 访问权限
- **API 统计**：查看应用的 API 调用统计

### 9.5 权限与角色管理

#### 权限管理

系统内置了所有 API 接口的权限定义，管理员可以为角色分配权限。

#### 角色管理

- **创建角色**：定义角色名称、编码，并分配权限
- **编辑角色**：修改角色信息和权限
- **复制角色**：基于现有角色快速创建新角色（含权限复制）

### 9.6 部门管理

管理租户下的部门组织结构：

- **创建部门**：支持树形结构，可设置上级部门
- **编辑部门**：修改部门名称、编码、排序
- **删除部门**：删除部门（需无下级部门）

### 9.7 标签管理

管理用户标签：

- **创建标签**：填写标签名称、编码、颜色和描述
- **编辑标签**：修改标签信息
- **删除标签**：删除标签
- **用户标签绑定**：在用户编辑弹窗中为单个用户设置标签

### 9.8 审计日志

记录所有管理操作，包含：

- 操作时间
- 操作人
- 操作类型
- 操作详情
- IP 地址
- User Agent

支持按时间范围筛选和导出。

### 9.9 短信配置

配置租户级别的短信服务：

- **短信提供商**：支持 Mock（开发模式）和阿里云短信
- **AccessKey**：短信服务 AccessKey
- **签名**：短信签名
- **模板**：短信模板编码
- **测试功能**：发送测试短信验证配置是否正确

### 9.10 登录测试

管理员可以通过"登录测试"功能，输入任意用户的用户名和密码来测试登录是否正常。测试成功后会显示用户的完整登录凭证信息。

## 11. 数据模型与架构

### 11.1 核心实体关系

```
                    ┌─────────────────────────────────────────────────┐
                    │                   Tenant (租户)                  │
                    └──────┬──────────────┬──────────────┬─────────────┘
                           │              │              │
                    ┌──────▼──┐    ┌─────▼────┐   ┌────▼────┐
                    │  User   │    │Application│   │  Role   │
                    └────┬──┬─┘    └─────┬────┘   └────┬────┘
                         │ │             │             │
              ┌──────────┼─┼─────────────┼─────────────┤
              │          │ │             │             │
        ┌─────▼────┐ ┌───▼──▼───┐ ┌────▼────┐  ┌─────▼─────┐
        │UserProfile│ │SocialAcct│ │AppApiStat│  │ApiPermission│
        └──────────┘ └──────────┘ └─────────┘  └──────┬────┘
                                                      │
                    ┌────────────────────────────────┼────────────────┐
                    │                                │                │
             ┌──────▼──────┐               ┌─────────▼───┐   ┌─────▼─────┐
             │  UserRole   │               │AppRoleBinding│   │RolePermission
             └──────┬──────┘               └─────────────┘   └───────────┘
                    │
             ┌──────▼──────┐
             │    Role     │
             └─────────────┘
```

### 11.2 用户类型

| 类型值 | 显示名称 | 说明 |
|--------|---------|------|
| `internal` | 内部用户 | 企业内部员工，可正常访问系统 |
| `external` | 外部游客 | 外部访客，访问权限受限制 |

### 11.3 用户状态

| 状态值 | 说明 |
|--------|------|
| 1 | 正常 |
| 0 | 禁用 |

### 11.4 中间件执行链

```
请求 → TokenAuth → AppKeyAuth → AdminAuth → Permission → RateLimit → ApiStat → AuditLog → View
```

| 中间件 | 功能 |
|--------|------|
| TokenAuthenticationMiddleware | JWT Bearer Token 认证，解析用户身份 |
| AppKeyAuthenticationMiddleware | AppKey + HMAC-SHA256 Signature 认证 |
| AdminAuthenticationMiddleware | 租户管理员 / 超级管理员身份认证 |
| PermissionMiddleware | RBAC 权限校验 |
| RateLimitMiddleware | 请求限流（IP / AppKey） |
| ApiStatMiddleware | API 调用统计入库 |
| AuditLogMiddleware | 审计日志记录 |
