## 2. 主分类索引（AI 入口表）

### A. 认证 API 子文档

- **子文档路径**: [`document/apis/API_01_AUTH_v1.0.md`](../apis/API_01_AUTH_v1.0.md)
- **覆盖范围**: `/api/v1/auth/*`
- **典型场景**: 用户登录、登出、Token 刷新、获取/修改自己的资料、微信小程序登录、短信验证码登录
- **认证方式**: 大部分接口匿名访问（登录/发短信/社交登录），其余需在 Header 带 `Authorization: Bearer <access_token>`

### B. 开放 API 子文档

- **子文档路径**: [`document/apis/API_02_OPEN_v1.0.md`](../apis/API_02_OPEN_v1.0.md)
- **覆盖范围**: `/api/v1/open/*`
- **典型场景**: 第三方系统校验 token、按 token 查/改用户资料、批量管理用户、检查用户权限、微信 access_token / 手机号
- **认证方式**: 应用签名（HMAC-SHA256），Header 必带 `X-App-Key`、`X-Timestamp`、`X-Signature`；URL 或 Header 另带 `access_token`
- **附带说明**: 完整签名算法、权限码清单、租户隔离规则详见子文档；历史上曾经合订在 `document/archive/gateway_openapi_documentation_v2.md`，新版以本路由拆出的子文档为准。

### C. 企业管理后台 API 子文档

- **子文档路径**: [`document/apis/API_03_ADMIN_v1.0.md`](../apis/API_03_ADMIN_v1.0.md)
- **覆盖范围**: `/api/v1/admin/*`
- **典型场景**: Web 管理后台的仪表盘、用户/应用/角色/部门 CRUD、用户导入导出、审计日志、应用 API 调用统计
- **认证方式**: 与企业管理后台前端共用 Session / Token，需 `is_staff=True`

### D. 超级管理员 API 子文档

- **子文档路径**: [`document/apis/API_04_SUPERADMIN_v1.0.md`](../apis/API_04_SUPERADMIN_v1.0.md)
- **覆盖范围**: `/api/v1/superadmin/*`
- **典型场景**: 平台总览统计、租户 CRUD、跨租户审计、平台配置、模拟进入租户
- **认证方式**: 需 `is_superuser=True`

## 3. 全局公共约定（所有接口通用）

以下约定**适用于全部 4 类 API**，子文档不再重复：

### 3.1 Base URL

- 开发环境: `http://localhost:8000`
- 生产环境: 由部署方提供，以 Nginx / 域名为准

### 3.2 请求 / 响应格式

- 请求体: `application/json; charset=utf-8`
- 响应体: 统一 JSON，结构如下：

  ```json
  {
    "code": 0,
    "msg": "ok",
    "data": {}
  }
  ```

  - `code = 0` 表示成功；非 0 表示业务错误。
  - `msg` 为错误/提示文案，`data` 为业务数据。

### 3.3 时间戳与编码

- 所有时间字段为 **ISO 8601 字符串**或 Unix 秒，具体以子文档为准。
- 所有文本字段使用 UTF-8。

### 3.4 通用 HTTP 状态码

| HTTP 状态码 | 含义                            |
| --------- | ----------------------------- |
| 200       | 成功（业务结果看 `code`）              |
| 400       | 参数错误                          |
| 401       | 未认证 / Token 失效               |
| 403       | 已认证但无权限                      |
| 404       | 资源不存在                         |
| 429       | 请求过于频繁（被 RateLimit 拦截）      |
| 500       | 服务内部错误                        |

### 3.5 中间件链（按请求顺序）

```
RateLimit → AppAuth → TokenAuth → AdminAuth → Permission → AuditLog → ApiStat → View
```

- 未匹配的 URL 前缀会被对应中间件直接放行或拒绝，具体行为见子文档"认证要求"小节。
